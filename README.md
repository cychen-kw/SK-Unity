# Silver Knights Unity — Windows 測試版

此儲存庫提供遊戲下載，不包含 Unity 專案原始碼。

## 下載

[下載 Windows x64 ZIP](https://github.com/cychen-kw/SK-Unity/releases/download/v0.1.0/SilverKnights-Windows-x64.zip) · [版本說明](https://github.com/cychen-kw/SK-Unity/releases/tag/v0.1.0)

完整解壓後執行 `SilverKnights/SilverKnights.exe`。請保留整個資料夾，不要單獨移動 EXE。不需要安裝 Unity。

Windows x64／Direct3D 11／鍵盤滑鼠。WASD 移動、同方向雙擊後按住衝刺、Space 上升、滑鼠瞄準、左鍵攻擊、1/2/3 換武裝、E 技能、Esc 暫停、F1 回選單、F5 重開。

包含 Philotes、Zephyrus、Gigantes、Icarus 四台機體與機庫。

此為測試版，建置及 ZIP 完整性檢查通過，尚未在原生 Windows 環境啟動驗證。
